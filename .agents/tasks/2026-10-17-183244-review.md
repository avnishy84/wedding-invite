## High-level view

Hero stacks mandala SVG (rotating 120s), toran SVG (swaying 4s), arch frame, and centered text on a single CSS grid cell using `grid-area: 1 / 1`. Names shimmer once via gradient background-clip. All three animations wrapped in prefers-reduced-motion media queries.

useCountdown manually calculates Asia/Kolkata's UTC+5:30 offset (330 minutes) because native Date timezone handling doesn't reliably expose millisecond-precision timestamps for half-hour offset zones across browsers. Returns days/hours/minutes/seconds breakdown plus isPast flag, updating via setInterval every second with proper cleanup.

ics.ts generates iCalendar strings with `DTSTART;TZID=Asia/Kolkata:YYYYMMDDTHHmmss` by stripping dashes and colons from ISO datetime. Now properly accepts lang parameter and uses `event.name[lang]` instead of hardcoded `.en` fields—calendar downloads respect UI language setting.

Events component formats dates with Intl.DateTimeFormat using `{ dateStyle: 'long', timeStyle: 'short', timeZone: 'Asia/Kolkata' }`, switching locale between 'hi-IN' and 'en-IN'. Each card overlays a mandala watermark at 8% opacity behind parchment background. "Add to Calendar" button passes lang parameter correctly.

Gallery lazy-loads Lightbox via React.lazy + Suspense. Lightbox implements keyboard navigation (Escape/ArrowLeft/ArrowRight) via useEffect keydown listener and focuses dialog on mount. Focus trap isn't fully implemented—Tab can escape to body—but with only three buttons (close, prev, next), real-world impact is minimal.

TopBar now exists as separate component files (TopBar.tsx and TopBar.module.css) with LangToggle and a disabled MusicToggle placeholder button. Sticky positioning at top with semi-transparent ivory background. MusicToggle shows speaker emoji with aria-label and disabled state with title "Coming in Phase 6."

App.tsx assembles all sections in correct order with OrnamentDividers between major sections. Each section except Hero and TopBar receives `ref={useReveal()}` for scroll-triggered fade-up animations.

## useCountdown timezone arithmetic and interval cleanup

useCountdown.ts manually calculates Asia/Kolkata UTC+5:30 by subtracting 330 minutes from `Date.UTC(year, month - 1, day, hour, minute, second)` (lines 14-19). This avoids browser-local-time interpretation of the ISO string, which would break for users outside India. Intl.DateTimeFormat can't expose the millisecond timestamp needed for countdown math.

setInterval updates state every 1000ms with proper cleanup on unmount (lines 48-50).

## ics.ts RFC 5545 compliance with bilingual support

generateIcs properly uses lang parameter to pull `event.name[lang]`, `event.venue[lang]`, `event.dressCode[lang]` (lines 10-12). Calendar downloads now respect UI language.

RFC 5545 line-folding (≤75 octets) not implemented. Long venue names violate the spec but calendar apps are lenient—minor non-compliance, doesn't block Phase 4.

## Gallery lazy-loading and Lightbox keyboard nav

Focus trap incomplete—Tab can escape to underlying page. Full WCAG 2.4.3 compliance requires querying focusables and cycling Tab/Shift+Tab. With only three buttons (close, prev, next), real-world impact minimal.
